# Threat Hunting

Amazon Security Lake data was queried using Amazon Athena.

The hunting process was used to investigate security findings and activity across multiple data sources.

## Data Sources

- Security Hub Findings
- VPC Flow Logs
- S3 Data Events

## Hunting Areas

- Security findings
- Network activity
- S3 object activity
- Suspicious security activity
- Cross-source investigation

The queries are maintained as a reusable hunting library.
